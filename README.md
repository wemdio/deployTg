# Telegram Auto-Responder - Worker 🤖

Telegram Worker для обработки диалогов и автоматических ответов с использованием AI.

## 🚀 Быстрый старт для Timeweb Cloud (Production)

### Шаг 1: Настройте переменные окружения в Timeweb

Откройте настройки вашего Worker приложения в Timeweb Cloud и добавьте следующие **обязательные** переменные окружения:

| Переменная | Описание | Пример |
|------------|----------|--------|
| `OPENAI_API_KEY` | OpenAI API ключ | `sk-proj-...` |
| `TARGET_CHAT_POSITIVE` | Telegram чат для заинтересованных | `@positive_channel` или `-1001234567890` |
| `TARGET_CHAT_NEGATIVE` | Telegram чат для отказавшихся | `@negative_channel` или `-1001234567890` |

### Шаг 2: Добавьте опциональные переменные (рекомендуется)

| Переменная | Описание | Значение по умолчанию |
|------------|----------|----------------------|
| `PROJECT_NAME` | Название вашего проекта | `""` |
| `OPENAI_MODEL` | Модель OpenAI | `gpt-4o-mini` |
| `TIMEZONE_OFFSET` | Часовой пояс (UTC+N) | `3` |

### Шаг 3: Загрузите файлы через SSH

Подключитесь к серверу по SSH и создайте файлы:

```bash
# Создайте prompt.txt с системным промптом для AI
cat > /app/prompt.txt << 'EOF'
Ты - AI ассистент для автоматических ответов в Telegram.
Твоя задача - естественно и по делу отвечать на сообщения пользователей.

Используй триггерные фразы:
- "{trigger_phrase_positive}" - когда пользователь заинтересован
- "{trigger_phrase_negative}" - когда пользователь отказывается
EOF

# Создайте папки для данных
mkdir -p /app/data/sessions
```

### Шаг 4: Загрузите Telegram сессии

Загрузите ваши `.session` файлы и соответствующие `.json` файлы в `/app/data/sessions/`:

Пример `.json` файла для сессии (`12345.json`):
```json
{
  "api_id": 12345,
  "api_hash": "your_api_hash_here",
  "proxy": "socks5://user:pass@host:port"
}
```

### Шаг 5: Перезапустите приложение

Worker готов к работе! 🎉

## 📋 Полный список переменных окружения

### ✅ **Обязательные переменные**

#### `OPENAI_API_KEY` ⚠️
- **Описание**: OpenAI API ключ для генерации ответов
- **Обязательно**: Да
- **Пример**: `sk-proj-abc123...`

#### `TARGET_CHAT_POSITIVE` ⚠️
- **Описание**: Telegram чат куда пересылать диалоги заинтересованных пользователей
- **Обязательно**: Да
- **Формат**: `@channel_name` или `-1001234567890`
- **Пример**: `@positive_leads`

#### `TARGET_CHAT_NEGATIVE` ⚠️
- **Описание**: Telegram чат куда пересылать диалоги отказавшихся пользователей
- **Обязательно**: Да
- **Формат**: `@channel_name` или `-1001234567890`
- **Пример**: `@negative_leads`

---

### 🎨 **OpenAI настройки**

#### `OPENAI_MODEL`
- **Описание**: Модель OpenAI для генерации ответов
- **По умолчанию**: `gpt-4o-mini`
- **Пример**: `gpt-4`, `gpt-4o-mini`, `gpt-3.5-turbo`

#### `OPENAI_SYSTEM_TXT`
- **Описание**: Путь к файлу с системным промптом
- **По умолчанию**: `prompt.txt`
- **Пример**: `prompt.txt`

#### `OPENAI_PROXY`
- **Описание**: HTTP/SOCKS прокси для OpenAI API
- **По умолчанию**: `null` (без прокси)
- **Формат**: `http://host:port` или `socks5://user:pass@host:port`

#### `TRIGGER_PHRASE_POSITIVE`
- **Описание**: Фраза в ответе AI, означающая что пользователь заинтересован
- **По умолчанию**: `[INTERESTED]`
- **Пример**: `[INTERESTED]`, `Отлично, рад что заинтересовал`

#### `TRIGGER_PHRASE_NEGATIVE`
- **Описание**: Фраза в ответе AI, означающая что пользователь отказался
- **По умолчанию**: `[NOT_INTERESTED]`
- **Пример**: `[NOT_INTERESTED]`, `Вижу что не заинтересовал`

#### `USE_FALLBACK_ON_OPENAI_FAIL`
- **Описание**: Использовать fallback текст при ошибке OpenAI
- **По умолчанию**: `false`
- **Формат**: `true` или `false`

#### `FALLBACK_TEXT`
- **Описание**: Текст для отправки при ошибке OpenAI
- **По умолчанию**: `""` (пустая строка)
- **Пример**: `Извините, я сейчас занят. Напишу позже.`

---

### 🔧 **Общие настройки**

#### `WORK_FOLDER`
- **Описание**: Папка для хранения данных
- **По умолчанию**: `data`

#### `PROCESSED_FILE`
- **Описание**: Файл со списком обработанных пользователей
- **По умолчанию**: `processed_clients.txt`

#### `PROJECT_NAME`
- **Описание**: Название проекта (для пометок в пересылаемых сообщениях)
- **По умолчанию**: `""` (пустая строка)
- **Пример**: `Моя рекламная кампания`

#### `TIMEZONE_OFFSET`
- **Описание**: Смещение часового пояса от UTC (в часах)
- **По умолчанию**: `3` (МСК)
- **Пример**: `0` (UTC), `3` (МСК), `-5` (EST)

---

### 📱 **Telegram настройки**

#### `TELEGRAM_FORWARD_LIMIT`
- **Описание**: Количество сообщений для пересылки в целевой чат
- **По умолчанию**: `5`
- **Пример**: `10`

#### `TELEGRAM_HISTORY_LIMIT`
- **Описание**: Количество сообщений истории для загрузки
- **По умолчанию**: `100`
- **Пример**: `50`

#### `REPLY_ONLY_IF_PREVIOUSLY_WROTE`
- **Описание**: Отвечать только если ранее писали этому пользователю
- **По умолчанию**: `true`
- **Формат**: `true` или `false`

---

### ⏱️ **Задержки и таймауты**

Все диапазоны задаются в формате JSON: `[min, max]` (в секундах)

#### `PRE_READ_DELAY_RANGE`
- **Описание**: Задержка перед прочтением сообщения
- **По умолчанию**: `[2, 5]`
- **Формат**: `[2, 5]` означает от 2 до 5 секунд
- **Пример**: `[3, 10]`

#### `READ_REPLY_DELAY_RANGE`
- **Описание**: Задержка между прочтением и ответом
- **По умолчанию**: `[3, 8]`
- **Пример**: `[5, 15]`

#### `ACCOUNT_LOOP_DELAY_RANGE`
- **Описание**: Задержка между обработкой разных аккаунтов
- **По умолчанию**: `[60, 120]`
- **Пример**: `[90, 180]`

#### `CHECK_NEW_MSG_INTERVAL_RANGE`
- **Описание**: Интервал проверки новых сообщений
- **По умолчанию**: `[5, 10]`
- **Пример**: `[7, 12]`

#### `DIALOG_WAIT_WINDOW_RANGE`
- **Описание**: Окно ожидания новых сообщений в диалоге
- **По умолчанию**: `[30, 60]`
- **Пример**: `[40, 90]`

---

### 😴 **Периоды сна**

#### `SLEEP_PERIODS`
- **Описание**: Периоды когда worker не работает (для имитации человеческого режима)
- **По умолчанию**: `""` (не спит)
- **Формат 1 (строка)**: `21:00-08:00,13:00-14:00`
- **Формат 2 (JSON массив)**: `["21:00-08:00", "13:00-14:00"]`
- **Пример**: `20:00-08:00,13:00-14:30` (ночной сон + обед)

## ⚙️ Приоритет конфигурации

Worker читает настройки в следующем порядке приоритета:

1. ✅ **Переменные окружения (ENV)** - наивысший приоритет
2. 📄 **config.json** - если нет ENV
3. 🔧 **Дефолтные значения** - если нет ни ENV, ни config.json

**Рекомендация для production:** Используйте только ENV переменные для безопасности!

## 🐳 Для Timeweb Cloud

### Настройки деплоя:

- **Тип приложения**: `backend`
- **Фреймворк**: `docker` или `flask`
- **Команда сборки**: `pip install -r requirements.txt`
- **Команда запуска**: `python main.py`
- **Порт**: не требуется (worker не открывает порты)

### После создания приложения:

1. ✅ Добавьте ENV переменные в настройках приложения
2. ✅ Загрузите `prompt.txt` через SSH
3. ✅ Загрузите Telegram сессии в `/app/data/sessions/` через SSH
4. ✅ Перезапустите приложение

---

## 🆘 Поддержка

При возникновении проблем проверьте логи приложения в Timeweb Cloud.

Типичные ошибки:
- ❌ `ERROR: OPENAI_API_KEY is required!` → Добавьте `OPENAI_API_KEY` в ENV
- ❌ `ERROR: Target chats are required!` → Добавьте `TARGET_CHAT_POSITIVE` и `TARGET_CHAT_NEGATIVE` в ENV
- ❌ `FileNotFoundError: prompt.txt` → Создайте файл `prompt.txt` на сервере

## 📝 Пример полной конфигурации через ENV

Скопируйте эти переменные в настройки Timeweb Cloud:

```bash
# Обязательные
OPENAI_API_KEY=sk-proj-your-key-here
TARGET_CHAT_POSITIVE=@positive_channel
TARGET_CHAT_NEGATIVE=@negative_channel

# Рекомендуемые
PROJECT_NAME=My Campaign
OPENAI_MODEL=gpt-4o-mini
TIMEZONE_OFFSET=3

# Опциональные (можно не указывать - будут дефолты)
TRIGGER_PHRASE_POSITIVE=[INTERESTED]
TRIGGER_PHRASE_NEGATIVE=[NOT_INTERESTED]
TELEGRAM_FORWARD_LIMIT=5
PRE_READ_DELAY_RANGE=[2,5]
READ_REPLY_DELAY_RANGE=[3,8]
SLEEP_PERIODS=21:00-08:00,13:00-14:00
```
