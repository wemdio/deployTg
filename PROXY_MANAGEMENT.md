# 🔐 Управление прокси

## Обзор

Система поддерживает два режима работы с прокси:

1. **Привязанные прокси** - каждый аккаунт имеет свой конкретный прокси
2. **Общий пул прокси** - прокси автоматически распределяются между аккаунтами

---

## 📋 Работа с прокси во Frontend

### Добавление прокси

1. Откройте вкладку **"Аккаунты"** в кампании
2. Найдите секцию **"🔐 Список прокси"**
3. Введите прокси (по одному на строку):
   ```
   socks5://user:pass@host:port
   http://user:pass@host:port
   ```
4. Нажмите **"💾 Сохранить прокси"**

### Очистка прокси

Нажмите **"🗑️ Очистить прокси"** для удаления всего списка.

---

## 🔗 Привязка прокси к аккаунтам

### Способ 1: При редактировании аккаунта

1. Нажмите **✏️** рядом с аккаунтом
2. В поле **"Прокси"** вы увидите:
   - Кнопку **"📋 Выбрать из списка"** (если прокси сохранены)
   - Возможность ввести прокси вручную
3. При выборе из списка вы увидите:
   - **Список всех сохранённых прокси**
   - **Цифра в оранжевом бейдже** - количество аккаунтов, использующих этот прокси
4. Нажмите **"Сохранить"**

### Способ 2: Ручной ввод

Вы можете ввести прокси вручную в поле, даже если он отсутствует в списке.

---

## 🚀 Логика работы при запуске кампании

### Если есть привязанные прокси

Backend создаёт файл `proxies.txt` в специальном формате:

```
account1.session:socks5://user1:pass1@host1:1080
account2.session:http://user2:pass2@host2:8080
```

Worker использует **конкретный прокси для конкретного аккаунта**.

### Если прокси НЕ привязаны

Backend создаёт `proxies.txt` со списком прокси:

```
socks5://user1:pass1@host1:1080
http://user2:pass2@host2:8080
```

Worker **автоматически распределяет** прокси между аккаунтами (round-robin).

### Если прокси вообще нет

Worker работает **без прокси**.

---

## 💡 Рекомендации

### ✅ Используйте привязку прокси, если:

- У вас есть выделенные прокси для каждого аккаунта
- Вы хотите контролировать, какой аккаунт через какой прокси работает
- У вас разные типы прокси (HTTP/SOCKS5) для разных аккаунтов

### ✅ Используйте общий пул, если:

- У вас много прокси и много аккаунтов
- Прокси взаимозаменяемы
- Вы хотите автоматическое распределение

---

## 🔍 Мониторинг использования прокси

В интерфейсе редактирования аккаунта вы видите **счётчик использования** каждого прокси.

Например:
- `socks5://...` **2** - этот прокси используется 2 аккаунтами
- `http://...` **0** - этот прокси никем не используется

Это помогает:
- Равномерно распределять нагрузку
- Избегать перегрузки одного прокси
- Видеть неиспользуемые прокси

  "session_name": "account1",

```json
{

  "name": "Моя кампания",
  "proxy_list": "socks5://...\nhttp://...",  // <- Общий пул прокси
  "accounts": [...]
}
```

## 🐛 Устранение неполадок

### Прокси не сохраняются

1. Убедитесь, что нажали **"💾 Сохранить прокси"**
2. Проверьте консоль браузера (F12)
3. Убедитесь, что backend запущен

### Счётчик использования показывает 0

- Это нормально, если прокси только что добавлен
- Привяжите прокси к аккаунту через редактирование

### Worker не использует прокси

1. Проверьте файл `proxies.txt` в runtime папке кампании
2. Убедитесь, что формат прокси корректен
3. Проверьте логи worker

## 📝 Формат прокси

### SOCKS5

```
socks5://username:password@hostname:port
socks5://192.168.1.1:1080  # без авторизации
```

### HTTP/HTTPS

```
http://username:password@hostname:port
https://username:password@hostname:port
```
